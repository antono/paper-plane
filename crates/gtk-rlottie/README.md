# gtk-rlottie

GTK widget (`gtk_rlottie::Animation`) that renders Lottie animations and Telegram
`.tgs` stickers using [rlottie](https://github.com/paper-plane-developers/rlottie).

Originally developed as a separate repository at
<https://github.com/paper-plane-developers/gtk-rlottie-rs> (last release v0.9.0)
and moved into the Paper Plane workspace, since Paper Plane is its only user.
